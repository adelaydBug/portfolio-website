# Adelaide Ternida | Portfolio

A single-page portfolio website built with HTML, CSS, JavaScript, PHP and MySQL.

## Features
- Light and dark theme
- Project cards loaded from a MySQL database
- Project detail modal
- Contact form and sign in

## Run locally
1. Install XAMPP and start Apache and MySQL.
2. Copy this folder into `C:\xampp\htdocs\`.
3. In phpMyAdmin, import `database/portfolio.sql`.
4. Open `http://localhost/portfolio-website/`.
